## 1. 目标与边界

### 1.1 项目目标

把用户上传的图片转换为可照着拼的拼豆图纸，输出网格、色号、图例和用量。免费、开源、零后端，图片只在设备本地处理。

### 1.2 P0 范围

| 模块 | 内容 |
|---|---|
| 图片导入 | 相册/拍照；JPEG/PNG/HEIC；EXIF 方向；长边上限 4096px |
| 裁剪适配 | 按目标比例居中裁剪或留白填充 |
| 参数 | 尺寸、颜色数、色卡、抖动、背景、亮度/对比度/饱和度 |
| 预览 | 网格缩放拖拽、点格查看色号、原图/图纸切换 |
| 结果 | 图例（色块 + 色号 + HEX + 颗数）、总颗数、底板数量估算 |
| 导出 | 长图 PNG（网格 + 图例 + 用量）、保存相册、分享图片 |
| 历史 | 最近 20 条参数与缩略图，可重开、删除 |
| 色卡 | 内置通用参考色卡；导入 JSON/CSV；显示来源与非官方标识 |

### 1.3 非目标

小程序首版明确不做：

- 逐格编辑、整色替换、手动画笔；
- 用户账号、云同步、社区、支付、广告；
- 后端服务、数据库、对象存储；
- AI 生图、自动抠图；
- 内置未确认授权的品牌色卡数据。

高级编辑与社区留给未来的桌面端 Next.js 产品，复用 `packages/core` 与 `PatternDocument`。

## 2. 技术基线

| 层 | 选择 |
|---|---|
| 框架 | Taro 4.3.3 + React 18.3.1 + TypeScript 5.6 |
| 构建 | Vite 5.4.0 |
| 样式 | Tailwind CSS 4.3.5 + `weapp-tailwindcss` 5.7.5 |
| UI | 自建 `packages/ui`，不使用组件库 |
| 状态 | Zustand 5，persist + migrate |
| 校验 | TypeScript + zod 4 |
| 质量 | Biome 2 + Vitest 3 |
| 包管理 | pnpm 8 workspace，Node 22 LTS（CI） |
| 图纸渲染 | Canvas 2D |
| 构建产物 | `apps/mini/dist/weapp`、`dist/h5`，后续 `dist/alipay`、`dist/tt` |

约束：

- 微信开发者工具打开 `apps/mini`，`miniprogramRoot` 为 `dist/weapp/`；
- 小程序所有图像处理在端侧完成，不发起上传请求；
- `packages/core` 不依赖 Taro 或 `wx.*`，可在 Node 直接测试；
- 色卡使用 `PaletteManifest` 模型，品牌色卡不写死在算法中。

### 3.3 发布

### 3.4 完成定义（DoD）

一个任务只有同时满足以下条件才算完成：

1. 代码已实现并合并到 `main`；
2. 对应单元测试/黄金图通过；
3. `pnpm lint`、`pnpm typecheck`、`pnpm test` 通过；
4. `pnpm build:weapp` 与 `pnpm build:h5` 通过；
5. 涉及界面的任务已在 H5 与微信开发者工具中手动验证；
6. 文档或注释已同步更新。

## 5. 测试与验收

### 5.1 测试分层

| 层 | 工具 | 位置 | 覆盖 |
|---|---|---|---|
| L1 单元 | Vitest | CI | 色彩、降采样、量化、网格、BOM、导入解析 |
| L2 属性 | fast-check | CI | 不变量与边界 |
| L3 黄金图 | Vitest + pngjs | CI | 固定输入 → 网格 JSON + 渲染 PNG |
| L4 H5 E2E | Playwright | CI | 上传 → 参数 → 生成 → 导出 |
| L5 真机 | 微信开发者工具 + 真机 | 发版前 | 权限、内存、导出、分享、性能 |
| L6 合规 | 手工清单 | 发版前 | 隐私、权限、无上传、色卡标识 |

### 5.2 核心用例

**色彩与量化**

- sRGB↔Lab 往返误差 <1e-6；
- 已知颜色 → 预期最近色号；
- 中位切分输出 ≤ K 色且确定性；
- k-means 同输入同输出；
- 单色图、全透明图、全黑图、1×1 图；
- 颜色数大于唯一色数时收敛；
- 抖动开关差异明显且误差不越界；
- 低频色合并后总格数不变。

**图像与网格**

- 面积加权降采样尺寸与均值正确；
- 极端宽高比、超长边；
- EXIF 旋转方向正确；
- 每格必属色卡；
- 颗数求和 = 宽×高；
- 符号唯一且与图例一致；
- 底板数量计算正确。

**色卡导入**

- 合法 JSON/CSV；
- 重复色号、非法 HEX、缺字段、超大文件、BOM/编码异常；
- 导入后来源标识与“非官方”提示正确。

**渲染与导出**

- 网格线、边界格、图例、合计位置正确；
- 分块拼接无错位；
- 最大尺寸导出成功；
- 保存/分享失败有降级。

### 5.3 黄金图矩阵

- 固定素材：5–10 张 CC0 小图（人像、风景、像素画、透明 PNG、极端对比）；
- 参数组合：尺寸 {29, 58, 87} × 配色 {通用 24, 自动 16} × 抖动 {开, 关}；
- 断言：网格 JSON 哈希 + 渲染 PNG 哈希；像素 diff 容差 0.1%；
- 更新：`pnpm golden:update`，PR 附新旧对比图；
- 大图不入库，由脚本生成，保证 clone 后测试一致。

### 5.4 性能基线

| 场景 | 目标 |
|---|---|
| 4096² 输入 → 58×58 | ≤ 1.5s（中端机） |
| 4096² 输入 → 87×87 | ≤ 3s |
| 最大导出 | ≤ 3000×4000，内存峰值可控 |
| 冷启动 | ≤ 2s |
| 主包 | ≤ 2MB，目标 1.5MB |

### 5.5 兼容矩阵

- iOS 15+ / Android 8+，微信最新版；
- H5：Chrome、Safari；
- 8000² 超大图、HEIC、透明 PNG、灰度图、损坏文件；
- 拒绝相册/相机权限、保存权限；
- 飞行模式完整流程；
- 低端 Android 连续生成 10 次不崩溃；
- 深色模式可读性（首版固定浅色主题也可）。

### 5.6 发布门禁

- **PR 门禁**：Biome + `tsc --noEmit` + 单元 + 黄金图 + weapp/H5 构建通过。
- **功能门禁**：E2E 通过；参数、预览、导出、历史、色卡导入全部走通。
- **发版门禁**：性能达标；双端手测清单全过；隐私政策与权限说明齐全；体验版试用无 P0 问题。

## 8. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| Taro Vite peer 警告 | 升级时可能构建失败 | 锁定版本；CI 构建冒烟；异常时评估 Vite 4 或 Tailwind 方案 |
| Canvas 端侧差异 | 预览/导出失败 | D01 先验证；适配器隔离；保留 H5 降级 |
| 大图内存不足 | 生成崩溃 | 输入长边上限 4096；逐级减半；及时释放 canvas |
| 包体超限 | 无法上传/审核 | 主包 ≤2MB；按需分包；不引重型依赖 |
| 色卡授权 | 法律/审核风险 | 不内置未授权品牌数据；用户导入；保留来源字段 |
| 备案/类目 | 上线延迟 | 并行办理；类目按后台当期清单选择 |
